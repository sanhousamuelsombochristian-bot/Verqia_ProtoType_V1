# Prototype de design (référence)

Fichiers `.dc.html` du prototype visuel publié sur claude.ai (artefact « Design »).
Ils servent de **référence visuelle** : ils s'ouvrent dans l'éditeur de design, pas directement
dans un navigateur (ils dépendent du moteur d'affichage de l'artefact).

Le code exécutable de l'application se trouve dans `frontend/` (React + TypeScript) et `backend/` (Python).
