# Frontend VERQIA PILOT

React 18 + TypeScript + Vite. Voir le README à la racine.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/
npm run typecheck
npm test
```

Ajouter une page : créer `src/pages/app/MaPage/{MaPage.tsx, MaPage.css, index.ts}`,
puis la déclarer dans `src/App.tsx` et, si besoin, dans `components/layout/AppLayout/navigation.ts`.
